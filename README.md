# Smart Travel Planner

Smart Travel Planner is a **React + Vite web application** that helps users create optimized multi-destination itineraries. Users can plan trips, visualize routes, add notes per stop, and export the itinerary as a PDF.

---

## Features

- Add stops by clicking on the map or using the search bar.
- Drag markers to manually reorder stops.
- Automatically optimize the route using a TSP-like algorithm.
- Animated route polyline showing the order of stops.
- Attach notes to each stop (e.g., things to do, reminders).
- Export a professional PDF itinerary with stop names, coordinates, and notes.

---

## Tech Stack

- **Frontend:** React + Vite  
- **Mapping:** Leaflet with custom markers  
- **Routing & Optimization:** TSP heuristic  
- **Animations:** Framer Motion  
- **Export:** jsPDF + html2canvas  
- **Styling:** CSS modules
